# 🎬 24/7 YouTube Live Streaming Automation (Telegram Controlled)

এই প্রজেক্টের মাধ্যমে আপনি যেকোনো প্রি-রেকর্ডেড ভিডিও **২৪/৭ নিরবচ্ছিন্নভাবে ইউটিউবে লাইভ স্ট্রিম** করতে পারবেন এবং সম্পূর্ণ সিস্টেমটি দূর থেকেই **টেলিগ্রাম বট** দিয়ে নিয়ন্ত্রণ করতে পারবেন।

---

## ✨ প্রধান ফিচারসমূহ:

1. **📱 শর্টস এবং 🖥️ লং লাইভ ফরম্যাট:**
   - **Long Video (16:9 Landscape):** ফুল এইচডি (1080p) ল্যান্ডস্কেপ লাইভ স্ট্রিম।
   - **Shorts Live (9:16 Vertical):** ইউটিউব শর্টস ফিডে লাইভ হওয়ার জন্য স্বয়ংক্রিয় ভার্টিক্যাল স্কেলিং ও প্যাডিং।

2. **🤖 টেলিগ্রাম বট কন্ট্রোল প্যানেল:**
   - **ভিডিও স্টক ভিউ:** স্টকে থাকা সব ভিডিওর তালিকা (ফাইলের সাইজ, রেজোলিউশন ও দৈর্ঘ্য সহ) দেখা।
   - **ভিডিও সিলেক্ট ও রান:** বাটনে চাপ দিয়ে ভিডিও সিলেক্ট করে ফরম্যাট অনুযায়ী লাইভ শুরু করা।
   - **লাইভ স্ট্যাটাস ও আপটাইম:** লাইভ কতক্ষণ চলছে (Uptime), কোন ভিডিও চলছে এবং সার্ভার CPU/RAM ব্যবহার মনিটর করা।
   - **লাইভ বন্ধ (Stop Live):** এক ক্লিকেই লাইভ বন্ধ করা।
   - **লাইভ হিস্ট্রি:** পূর্ববর্তী লাইভ স্ট্রিমের রেকর্ড ও সময়কাল দেখা।

3. **📤 সরাসরি টেলিগ্রাম থেকে ভিডিও আপলোড:**
   - যেকোনো ভিডিও বা ফাইল টেলিগ্রাম বটের চ্যাটে সেন্ড করলে বট সেটি স্বয়ংক্রিয়ভাবে `videos/` ফোল্ডারে সেভ করবে এবং সাথে সাথেই লাইভ চালু করার অপশন দিবে।

4. **📁 ম্যানুয়াল ভিডিও স্টক:**
   - আপনি চাইলে সরাসরি কম্পিউটারের `videos/` ফোল্ডারেও আপনার ভিডিও পেস্ট করে রাখতে পারেন। বট স্বয়ংক্রিয়ভাবে তা শনাক্ত করবে।

5. **🔄 24/7 ইনফিনিট লুপ ও অটো-রিকানেক্ট (Watchdog):**
   - ভিডিও শেষ হলে স্বয়ংক্রিয়ভাবে আবার প্রথম থেকে শুরু হবে।
   - কোনো কারণে নেটওয়ার্ক ড্রপ বা সংযোগ বিচ্ছিন্ন হলে ৫ সেকেন্ড পর স্বয়ংক্রিয়ভাবে রি-কানেক্ট হবে।

6. **⚡ এক ক্লিকে চালু (`run.bat`):**
   - কোনো জটিল কমান্ড ছাড়াই কেবল `run.bat` ফাইলে ডাবল ক্লিক করলেই সবকিছু স্বয়ংক্রিয়ভাবে সেটআপ হয়ে চালু হয়ে যাবে।

## 🚀 সেটআপ ও ব্যবহারের নিয়মাবলী:

### ধাপ ১: টেলিগ্রাম বট ও স্ট্রিম কি সংগ্রহ
1. টেলিগ্রামে [@BotFather](https://t.me/BotFather)-এ গিয়ে `/newbot` লিখে একটি নতুন বট বানিয়ে **Bot Token** সংগ্রহ করুন।
2. ইউটিউব স্টুডিও (YouTube Studio -> Go Live)-এ গিয়ে আপনার **Stream Key** কপি করুন।

### ধাপ ২: কনফিগারেশন সেট করা
ফোল্ডারে থাকা `.env.example` ফাইলটির নাম পরিবর্তন করে `.env` রাখুন (বা `run.bat` চালালে স্বয়ংক্রিয়ভাবে তৈরি হবে) এবং আপনার টোকেনগুলো দিন:

```env
TELEGRAM_BOT_TOKEN=আপনার_টেলিগ্রাম_বট_টোকেন
YOUTUBE_STREAM_KEY=আপনার_ইউটিউব_স্ট্রিম_কি
TELEGRAM_ADMIN_ID=   # (ঐচ্ছিক: শুধু আপনার Telegram User ID দিতে পারেন সুরক্ষার জন্য)
```

> **টিপ:** আপনি চাইলে সরাসরি টেলিগ্রাম বট চালু করেও `/setkey your_stream_key` কমান্ড দিয়ে স্ট্রিম কি সেট করতে পারবেন।

### ধাপ ৩: সফটওয়্যার চালু করা
- `run.bat` ফাইলে **ডাবল ক্লিক (Double Click)** করুন।
- এটি স্বয়ংক্রিয়ভাবে প্রয়োজনীয় লাইব্রেরি ইনস্টল করে টেলিগ্রাম বট চালু করে দিবে।

### ধাপ ৪: টেলিগ্রাম থেকে নিয়ন্ত্রণ
- আপনার টেলিগ্রাম বটে গিয়ে `/start` চাপুন।
- স্ক্রিনে আসা মেনু বাটন ব্যবহার করে ভিডিও সিলেক্ট করুন, ফরম্যাট পছন্দ করুন এবং লাইভ উপভোগ করুন!

## 📂 ফাইল স্ট্রাকচার:

```
24Live/
├── videos/             # আপনার সব ভিডিও ফাইল এখানে থাকবে
├── logs/               # লাইভ স্ট্রিমের হিস্ট্রি এবং FFmpeg লগ
├── .env                # কনফিগারেশন ফাইল (টোকেন ও স্ট্রিম কি)
├── streamer.py         # FFmpeg ইঞ্জিন ও 24/7 অটো-লুপ কন্ট্রোলার
├── video_manager.py    # ভিডিও স্টক স্ক্যানার ও মেটাডাটা রিডার
├── bot.py              # টেলিগ্রাম বট লজিক ও ইন্টারঅ্যাক্টিভ বাটন মেনু
├── main.py             # মূল লঞ্চার স্ক্রিপ্ট
├── run.bat             # এক ক্লিকে উইন্ডোজে রান করার ফাইল
└── requirements.txt    # পাইথন ডিপেনডেন্সি
```
