================================================================================
           🖥️ Windows RDP / VPS One-Click Setup Guide (24/7 Live)
================================================================================

এই ফাইলে নতুন যেকোনো Windows RDP বা VPS-এ এক ক্লিকে সম্পূর্ণ প্রজেক্ট সেটআপ ও
রান করার সম্পূর্ণ কমান্ড এবং নির্দেশনা দেওয়া হলো।

--------------------------------------------------------------------------------
🚀 পদ্ধতি ১: সবচেয়ে সহজ ও এক-ক্লিকে সেটআপ (Recommended)
--------------------------------------------------------------------------------
১. আপনার Windows RDP-তে এই প্রজেক্ট ফোল্ডারটি ওপেন করুন (বা Git Clone করুন)।
২. ফোল্ডারের ভেতরে থাকা "setup_rdp.bat" ফাইলটিতে ডাবল ক্লিক (Double Click) করুন।

👉 "setup_rdp.bat" নিজে থেকেই:
   • পাইথন ও পিপ (pip) চেক ও আপডেট করবে।
   • যদি RDP-তে FFmpeg না থাকে, তবে স্বয়ংক্রিয়ভাবে ডাউনলোড ও কনফিগার করে নিবে।
   • সকল পাইথন লাইব্রেরি (python-telegram-bot, psutil, colorama ইত্যাদি) ইনস্টল করবে।
   • videos, thumbnails এবং logs ফোল্ডার তৈরি করবে।
   • সরাসরি 24/7 টেলিগ্রাম বট সার্ভিস রান করে দিবে!


--------------------------------------------------------------------------------
⚡ পদ্ধতি ২: PowerShell / CMD থেকে এক লাইনের কমান্ড (One-Liner)
--------------------------------------------------------------------------------
আপনার RDP-তে PowerShell বা Command Prompt (CMD) ওপেন করে প্রজেক্ট ফোল্ডারে এসে
নিচের কমান্ডটি একবারে রান করুন:

powershell -ExecutionPolicy Bypass -Command "pip install -r requirements.txt; python main.py"


--------------------------------------------------------------------------------
📋 নতুন RDP-তে প্রথমবার শুরু করার স্টেপ-বাই-স্টেপ গাইড:
--------------------------------------------------------------------------------
ধাপ ১: Git দিয়ে প্রজেক্ট ক্লোন করুন (অথবা জিপ ফাইল পেস্ট করুন):
       git clone <your_repo_url>
       cd 24Live

ধাপ ২: "setup_rdp.bat" ফাইলে ডাবল ক্লিক করুন।
       (এটি এক মিনিটের মধ্যে সব লাইব্রেরি ইনস্টল করে বট চালু করে দিবে)

ধাপ ৩: টেলিগ্রামে আপনার বটে গিয়ে /start চাপুন।
       • 🔑 স্ট্রিম কি সেট করতে: "⚙️ ইউটিউব সেটআপ" -> "🔑 স্ট্রিম কি সেট করুন"
       • 🎬 ভিডিও দিতে: সরাসরি টেলিগ্রাম চ্যাটে যেকোনো ভিডিও পাঠিয়ে দিন।
       • 🚀 লাইভ শুরু করতে: "🚀 লাইভ শুরু করুন" বাটনে চাপ দিয়ে লং/শর্টস সিলেক্ট করুন।


================================================================================
💡 RDP-তে 24/7 চালু রাখার জন্য গুরুত্বপূর্ণ টিপস:
================================================================================
১. RDP ডিসকানেক্ট করলেও যাতে লাইভ বন্ধ না হয়:
   • RDP-র উইন্ডো ক্লোজ করার সময় "Sign Out" বা "Log off" করবেন না।
   • কেবল উপরে থাকা নীল বার থেকে 'X' (Close) বাটনে চেপে RDP উইন্ডোটি কেটে দিন।
   • এতে RDP ব্যাকগ্রাউন্ডে সবসময় চালু থাকবে এবং আপনার লাইভ নিরবচ্ছিন্নভাবে চলবে!

২. ইন্টারনেট ড্রপ প্রোটেকশন:
   • RDP-তে কোনো কারণে ইন্টারনেট বিচ্ছিন্ন হলেও আমাদের স্ক্রিপ্ট ৫ সেকেন্ডের মধ্যে
     স্বয়ংক্রিয়ভাবে রি-কানেক্ট করে নিবে।
